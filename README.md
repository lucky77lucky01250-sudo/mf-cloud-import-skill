# mf-cloud-import

領収書・請求書の処理と、マネーフォワード クラウド確定申告への仕訳登録を助ける **Claude Code スキル**です。

個人事業主の「毎月の経理」を短くすることを目的にしています。

---

## できること

### 1. 領収書・請求書から仕訳をつくる

フォルダに溜めた画像（JPG/PNG）やPDFを読み取り、次を自動で行います。

- 日付・店舗名・金額・内容の抽出（撮影の向きが横・逆さでも読む）
- `MMDD_店舗名_内容_金額円.拡張子` へのリネーム
- キーワードによる勘定科目の自動判定
- MFクラウド取込用CSV（Shift-JIS）と、Excel管理ファイルの生成

### 2. 銀行・カード連携の明細から仕訳を登録する

MFクラウドに連携済みの口座・カードの未仕訳明細を、ブラウザ操作で登録する手順を収録しています。

- 複数カードが混ざる場合の分離方法
- カード払い経費の貸方を「未払金」で統一するルール
- 残高試算表での検算手順
- MFクラウドのUIの癖（一括登録が固まる、科目提案が誤りやすい 等）

## インストール

Claude Code のスキルフォルダへ直接クローンするのが簡単です。

```bash
git clone https://github.com/lucky77lucky01250-sudo/mf-cloud-import-skill.git ~/.claude/skills/mf-cloud-import
```

更新は `git pull` で受け取れます。

```bash
cd ~/.claude/skills/mf-cloud-import && git pull
```

> ZIPをダウンロードして展開する場合は、フォルダ名を **`mf-cloud-import`** にして `~/.claude/skills/` に置いてください。

インストール後、Claude Code を再起動すると認識されます。

## 使い方

Claude Code に日本語で頼むだけです。スキルは自動で発動します。

```
令和8年フォルダの領収書を整理して仕訳を作って
```

```
今月の未仕訳を登録して
```

## カスタマイズ

勘定科目の振分ルールは [`references/kamoku_rules.md`](references/kamoku_rules.md) にあります。
**業種によって適切な科目は変わります。** ご自身の事業に合わせて編集してください。

チャットで「〇〇は消耗品費にして」と伝えれば、そのルールを追記させることもできます。
